# LLM-Based Finance Agent

> An intelligent financial agent powered by Large Language Models (LLMs) that combines real-time news analysis with historical stock data to forecast future stock prices.

---

## Overview

This project integrates **Google Gemini 1.5 Pro**, **Yahoo Finance**, and **NewsAPI** into a unified agent pipeline that:

- Fetches historical stock price data for any publicly traded stock
- Retrieves relevant financial news headlines in real time
- Uses an LLM to reason over both data sources and predict the next trading day's closing price
- Backtests predictions against actual prices and evaluates performance using standard financial metrics

---

## Tech Stack

| Component | Technology |
|---|---|
| LLM | Google Gemini 1.5 Pro (`google-generativeai`) |
| Stock Data | Yahoo Finance (`yfinance`) |
| News Data | NewsAPI (`newsapi-python`) |
| ML Evaluation | scikit-learn |
| Visualization | matplotlib |
| Language | Python 3.10+ |

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/0xLemon571/LLM-based-Finance-Agent.git
cd LLM-based-Finance-Agent
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure API Keys

Create a `config.json` file in the root directory:

```json
{
    "news_api_key": "your_newsapi_key",
    "genai_api_key": "your_gemini_api_key",
    "model_name": "gemini-1.5-pro",
    "stock_symbol": "AAPL",
    "days": 30
}
```

| Key | Description | Get it here |
|---|---|---|
| `news_api_key` | NewsAPI key for fetching headlines | [newsapi.org](https://newsapi.org/) |
| `genai_api_key` | Google Gemini API key | [aistudio.google.com](https://aistudio.google.com/) |
| `model_name` | Gemini model to use | `gemini-1.5-pro` recommended |
| `stock_symbol` | Stock ticker symbol | e.g. `AAPL`, `TSLA`, `2330.tw` |
| `days` | Historical data window (days) | e.g. `30` |

## Usage

Run the backtesting pipeline over any date range:

```bash
python main.py
```

By default, `main.py` runs backtesting for **June 2024**. You can modify the date range inside `main.py`:

```python
start_date = datetime(2026, 6, 1)
end_date   = datetime(2026, 6, 30)
```

## Evaluation Metrics

After backtesting, the agent prints the following performance metrics:

| Metric | Description |
|---|---|
| **MSE** | Mean Squared Error |
| **RMSE** | Root Mean Squared Error |
| **MAE** | Mean Absolute Error |
| **R²** | Coefficient of Determination |
| **NDEI** | Non-Dimensional Error Index (RMSE / Std Dev) |

A plot of **Predicted vs Actual** prices is also generated automatically.
